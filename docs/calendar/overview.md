# Overview

### Calendar overview

Syncly gives you one calendar for tasks, events, and deadlines.

Use it to plan personal work, view team schedules, and track milestones in one place.

You can switch between personal and team views. You can also sync with external calendars like Google Calendar and Outlook.

### Event types

The calendar shows three entry types:

* **Tasks** for scheduled work.
* **Events** for meetings, reviews, and time blocks you create manually.
* **Milestones** for important project deadlines.

Each type uses its own color. You can filter each one independently to focus on the schedule you need.

### Team scheduling

Use the personal or team view toggle to switch from your schedule to a shared team calendar.

In team view, you can see availability across members. This helps you schedule work without extra back-and-forth.

Syncly flags conflicts when time overlaps. You can assign events directly from the calendar while planning work.

This is especially useful for sprint planning and cross-team coordination.

### Create and manage events

Create an event by clicking any date on the calendar.

When you create an event, you can add:

* **Title**
* **Project**
* **Attendees**
* **Recurrence rule**
* **Task attachment**

After you save the event, drag and drop it to reschedule it.

### External calendar sync

Set up calendar sync in **Settings → Integrations → Calendar**.

Once connected, events from Syncly can appear in your external calendar, and external calendar events can appear in Syncly.

Sync is one-way by default from Syncly to the external calendar. You can change it to two-way sync when you need updates to flow both directions.

{% hint style="info" %}
Connect sync early if your team already uses Google Calendar or Outlook for scheduling.
{% endhint %}
