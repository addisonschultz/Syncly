# Events

### Events

This is a mock page for event workflows.

Use this page to document how users create, edit, and manage events.

* Add titles, dates, and attendees.
* Configure reminders.
* Update recurring events.

### Booked meetings

Meetings booked through a [booking link](booking-links.md) appear as normal events on the link's calendar.

* The title is `<link title> — <invitee name>`, for example `Intro call with Alex — Jordan Lee`.
* You and the invitee are both attendees.
* The invitee's note becomes the event description.
* The event has one 15-minute reminder.

To cancel a booked meeting, delete the event.
