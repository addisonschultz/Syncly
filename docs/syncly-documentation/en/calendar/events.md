# Events

### Events

This is a mock page for event workflows.

Use this page to document how users create, edit, and manage events.

* Add titles, dates, and attendees.
* Configure reminders.
* Update recurring events.

### Booked meetings

Meetings booked through a [booking link](booking-links.md) appear as normal events on the destination calendar. The event title is the link title followed by the invitee's name, for example `Intro chat with Alex — Jordan Lee`. The invitee's note becomes the description, both of you are attendees, and you get a 15-minute reminder. To cancel a booked meeting, delete the event.
