# Events

### Events

This is a mock page for event workflows.

Use this page to document how users create, edit, and manage events.

* Add titles, dates, and attendees.
* Configure reminders.
* Update recurring events.

### Booked meetings

Meetings booked through a [booking link](booking-links.md) appear as normal events on the link's calendar. Each one has these details:

* **Title:** `<link title> — <invitee name>`, for example `Intro chat with Alex — Jordan Lee`.
* **Description:** the note the invitee added, if any.
* **Attendees:** you and the invitee.
* **Reminder:** 15 minutes before the start.

You can edit or delete a booked meeting like any other event. To cancel a booking, delete its event.
